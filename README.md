# 星塔旅人美术替换工具

[下载免安装包](https://github.com/waw1w1/Stella-Sora-Switch/releases/download/v1.0.0/Stella-Sora-Switch-Portable.zip)

## 安装环境

在工具目录执行：

```powershell
uv venv --python 3.11 .venv
uv pip install --python .venv\Scripts\python.exe -r requirements.txt
```

## 使用

| 文件 | 作用 |
| --- | --- |
| `一键替换.cmd` | 将日服兼容美术资源替换到国服，首次运行时选择两服目录。 |
| `一键恢复.cmd` | 恢复原版资源，更新游戏前先运行。 |
| `选择游戏目录.cmd` | 重新选择国服和日服目录。 |
| `校验替换.cmd` | 检查已替换文件是否完整、是否被更新覆盖。 |
